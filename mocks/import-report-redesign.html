Design notes

  • Outcome first: “3 failed” leads; timing is one quiet meta line.
  • Progressive disclosure: the whole report collapses; Failed opens by default, OK stays closed.
  • Status ≠ colour: icon tile + label + count, with a short helper under each bucket.
  • Dismissible: one card, one dismiss — no duplicate error banner under the library.
  • Brand colour: violet only on Import / Email / focus — not the card frame.
