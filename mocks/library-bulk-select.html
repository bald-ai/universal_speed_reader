Library bulk select

Long-press a book or folder to enter selection mode: checkboxes appear on the right, the pressed item is marked, then multi-select and run bulk actions. Nested folders use cascade select in this mock (see proposal at right).

Try it: press and hold (~0.45s) any book or folder — try Classics or Russian. On desktop you can also right-click. Folder check = whole subtree; partial = dash.

Interaction

  1. Idle — same Library as today: folders, books, … menus.
  2. Long-press — checkboxes on the right; pressed row checked.
  3. Folder tap — selects / clears the whole subtree (demo’d here).
  4. Partial — parent shows a dash when only some children are checked.
  5. Chevrons — still expand/collapse while selecting (so you can reach nested rows).

Nested folders — proposal

  1. A · Cascade (mocked) — checking a folder checks every descendant book + folder. Unchecking clears the subtree. Parents go indeterminate when mixed. Best for “delete this whole branch.”
  2. B · Folder as unit — folder checkbox only marks the folder itself; children stay independent. Matches today’s single-folder delete choice, but weaker for bulk cleanup.
  3. C · Visible-only cascade — folder selects only expanded/visible children. Collapsed books stay out. Safer, easier to miss nested items.

Bulk Delete: if any selected folder has books, reuse the existing sheet — “Delete folders only” vs “Delete folders + contents” — scoped to the selected set (not one folder at a time).

Count label: prefer “2 folders · 5 books” over raw row count when folders are included.
